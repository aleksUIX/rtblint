# FreeWheel needs a verified response contract before a full profile

Reviewed 2026-10-09. The official [outgoing request table](https://hub.freewheel.tv/x/goKnl) identifies a March 2, 2026 revision and DSP-configured OpenRTB 2.2, 2.5 or 2.6. The search reader exposes its cached table. Direct retrieval of this route returned 403; its canonical page route returned a JavaScript challenge rather than protocol content.

The table supplies useful producer evidence: fixed display manager strings, explicitly enumerated server-side modes, video metadata and deal-specific duration and key-value extensions. Its always-passed annotations describe FreeWheel's outgoing producer, not a supplier acceptance contract. Supply-chain inclusion requires account enablement. The seat row refers to an inconsistent response field and cannot prove mandatory response seats. Guaranteed timeout policy requires deal classification that is not unambiguously available.

The official resource directory names a response guide, but its substantive current response table was not retrieved. Public metadata guidance from 2023 does not establish a complete current response contract. No full FreeWheel profile is added. Implementing a few request annotations would overstate the available acceptance evidence. This deferral can be resolved with the current response specification and DSP configuration scope.
